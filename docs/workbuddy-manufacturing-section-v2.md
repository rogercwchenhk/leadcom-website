## 四、设计决策

1. **保留外层 `.use-case` 容器**：复用已有的 padding 和 border-bottom 样式，不需额外调整
2. **不引入新图标库**：全部使用页面已加载的 Tabler Icons 3.44.0
3. **不使用图片**：所有内容用 HTML 文本 + CSS 图标呈现
4. **去掉结尾金句**："AI不是替代工程师，而是让产线主管拥有100个数字助理" 不放入页面
5. **保留生态金句**："孤立的AI是玩具，连上生态的AI才是生产力" 作为生态协同区块的收尾引用
6. **命名前缀 `mfg-`**：与现有类名不冲突，语义清晰（manufacturing）
7. **配色复用现有变量**：`--copper`(蓝), `--ink`(深灰), `--sand`(浅灰), `--copper3`(浅蓝底)
8. **Hover 效果**：所有卡片统一 `background:var(--sand2)` 微交互

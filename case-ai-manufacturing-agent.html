某珠三角汽配制造企业日均处理 50+ 条供应商询价。人工比对费时、出错、响应慢。励康为其部署 SPARK 本地算力 + Hermes Agent 企业微信机器人，实现询报价全流程自动化。

项目背景

人工询报价：效率瓶颈卡住增长

该企业是珠三角某中型汽配制造工厂，年营收约 3 亿元，供应商超过 200 家。采购团队 5 人，每天需要处理来自供应商微信群、邮件和 ERP 系统的 50 多条询价请求。

每条询价需要：查阅历史报价记录 → 比对 3-5 家供应商价格 → 填写报价审批表 → 回复供应商。人工处理平均耗时 30 分钟/条，供应商平均等待 4 小时。

核心痛点：

  • 询报价响应慢导致供应商流失（竞争对手响应 < 1 小时）
  • 人工比对出错率约 8%，导致定价偏高或偏低
  • 历史报价数据散落在 Excel、微信群和邮件中，无法追溯利用
  • 采购数据涉及核心成本结构，管理层坚决要求数据不出厂区

解决方案

三层架构闭环：算力不出厂 + AI 打通企微

励康基于 AI 全栈三层架构，为该工厂量身定制了从底层算力到上层交互的完整方案：

第一层：算力引擎 — SPARK 本地部署

部署一台 SPARK 算力盒子（128GB 统一内存，CUDA 生态），直接接入工厂内网。运行 Qwen-14B 模型用于询报价智能匹配，数据全程不出厂区，满足管理层安全要求。

第二层：模型网关 — One API 统一管理

搭建 One API 模型网关，将本地 Qwen 模型与云端大模型（需要时）统一接入。实现 API Key 集中管理、成本追踪和请求审计。网关带自动故障转移——本地模型优先，峰值流量自动分流。

第三层：智能触达 — Hermes Agent + 企业微信

开发 Hermes AI 采购助手，集成到企业微信工作台。供应商在微信群发询价 → 机器人自动解析 → 对比历史价格库 → 生成报价建议 → 推送给采购员审批 → 一键回复供应商。

供应商群消息→Hermes Agent→One API 网关→SPARK + Qwen→报价建议

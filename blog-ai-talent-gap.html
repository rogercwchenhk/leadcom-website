AI 专业热度全国第三，但企业真正缺的人，大学还没教出来

2026-07-13 · 陈超伟 · 阅读 8 分钟

2026 年 7 月 2 日，百度高考大数据放榜。AI 专业（人工智能）以 9.1 万搜索热度排在本科专业热度榜第三名，仅次于电气工程和电子信息。

家长群里一片欢呼：风口，选它。

同一天，一个在东莞开汽配厂的老板，在志愿填报群里发了一条消息。这条消息让几百个家长安静了：

"我女儿想学工商管理。但我厂里刚上的 AI Agent，已经能自动处理询价、比价、下 PO 单了。以前是两个人干的活，现在一台服务器月租 1950 就搞定。这专业以后还有人要吗？"
—— 东莞某汽配厂老板，于 2026 高考志愿填报群

这个问题，比任何热搜榜单都更真实。

两个热搜，一个错位

最近的高考热搜，有两个现象放在一起看很有意味。

一个是 AI 专业热度爆表。电气工程、电子信息、人工智能霸榜 2026 本科专业热度前三，工科几乎包圆了前十名。

另一个是深圳大学以 40.7 万搜索热度登顶高校热度榜首，反超一众 985/211。媒体的解读是"这一届家长，终于开始算一笔新账"——从看学校标签，到看毕业后的真实竞争力。

两个热搜指向同一个方向：家长和学生都在焦虑"选什么专业以后能有好工作"。但他们不知道的是——挑选专业的人在焦虑，真正在招人的人也在焦虑。

我们在珠三角给 200 多家企业部署过 AI，跟各个行业的老板、IT 负责人聊过无数遍。他们嘴里最高频的一句话不是"AI 太贵了"，而是——

"会搭 AI 的人，简历根本收不到。"
—— 珠三角某制造企业 IT 负责人

这听起来很矛盾：AI 专业热度全国第三，每年毕业生成千上万，企业却说招不到人？

矛盾不在数量，在错位。

学校教的 AI vs 企业用的 AI，中间隔着一整个产业

我们先来看一张隐形的产业链分工图。

学术界的 AI：PyTorch、TensorFlow、Transformer 论文、ImageNet 竞赛、顶会投稿。目标是发表，评估标准是准确率提升 0.3 个百分点。

产业界的 AI：Dify 工作流搭建、API 网关调试、AMD/英伟达算力服务器运维、企业知识库对接、权限和合规配置。目标是把一套能跑通、能省钱、能复用的 Agent 塞进财务部或采购部的日常流程里。

这不是深浅的区别，是方向的区别。

一个真实案例：汽配厂的 AI 采购助手

我们 2026 年上半年部署的项目：为珠三角某汽配制造企业搭建 AI 采购助手。

工作内容：接入 3 家供应商的 API、配置比价规则逻辑、搭建审批工作流、对接企业微信通知、设置异常价格预警。技术栈是 Dify + 国产模型 + 企业微信开放接口。没有一行代码涉及神经网络训练。

项目上线后，询报价处理效率提升约 60%，替代了约 1.5 个全职采购文员的重复劳动。

"学校里没人教我怎么调 API 接口、怎么读供应商返回的 JSON、怎么设异常告警阈值。这些都是到了励康之后，在项目里手把手练出来的。"
—— 负责该项目的部署工程师，计算机科学专业毕业

这就是产业正在发生的真实图景：企业不缺"懂 AI 的人"，缺的是"能把 AI 塞进具体业务场景、让它真正干活的人"。

3 种 AI 岗位，企业抢着要，但简历一份都收不到

过去一年，我们观察到珠三角企业 AI 招聘需求里，有 3 类岗位的需求增速远超人才供给。它们有一个共同点：不需要顶尖名校硕士，但需要"会干活"。

岗位 1：AI 部署工程师

日常：搭建 AI Agent 运行环境（Dify / Hermes / OpenClaw），配置模型网关，管理 API Key 权限，调试工作流节点，对接企业内部系统（ERP / OA / 企业微信）。

技能：懂 Linux 基础运维、会读 API 文档、理解 token 消耗和模型选型逻辑、能在 AMD 或英伟达算力服务器上做环境部署。

💰 珠三角 1.2 万 - 2.5 万 / 月，一年经验供不应求

岗位 2：Agent 流程设计师

日常：把业务需求（比如"自动处理采购询价"）拆解成 Agent 能执行的工作流步骤，设计 prompt 模板，设定决策规则和异常处理逻辑。

技能：理解业务流程、有结构化思维、会用可视化工作流工具、能跟业务部门沟通需求。不需要写代码，但需要"能跟 AI 说清楚话"。

💰 1 万 - 1.8 万 / 月。采购跟单转型仅需 3 个月

岗位 3：IT + AI 复合型维保工程师

日常：维护企业 AI 服务器的稳定运行，处理硬件报错、系统故障、算力调度。同时监控 AI Agent 的运行状态，处理模型调用失败、积分消耗异常等问题。

技能：服务器运维（IBM / HP / Dell 等主流品牌）+ AI Agent 平台基础操作。两头都得会一点。

💰 1.5 万起。珠三角基本是"抢"的

这不是预测，这是正在发生的招聘现实。

问题的根源，不在学生，在"教"和"用"之间没有桥

我们不认为这是学生的错。一个高中生选专业的时候，他怎么知道企业里 AI 到底在干什么？他只能看专业名字、看就业率数字、看网上的零散信息。

问题的根源在于：大学教育的内容更新速度，跟不上产业 AI 落地的速度。

一个 Dify 工作流，半年迭代十几个版本。一个 Agent 部署的最佳实践，每个季度都在被重新定义。而大学的课程大纲，从编写到审批到落地，至少 2-3 年。

这不是任何一个群体的责任。学校在尽力，学生在努力，企业也在着急。但现实就是——桥还没有搭起来。

所以对企业来说，寄希望于"等大学培养出合适的 AI 人才"，不如问自己另一个问题：

"AI Agent 的部署门槛，已经低到一台月租 1950 的服务器就能跑起来。那为什么不先部署，再培养？"

我们看到的现实是：珠三角已经有越来越多中小企业走在前面。他们不再等待"完美的 AI 人才"出现，而是先上一套基础 AI Agent，让现有的员工在实际使用中慢慢学会配置、调试、优化。一个做过 3 年采购跟单的人，学 Dify 工作流只需要 3 个月——比培养一个应届生快得多，也靠谱得多。

励康的建议 企业 AI 部署的最佳策略：先用起来，再培养人。SPARK 方案月租 1950 起步，让现有员工边用边学，3 个月即可从业务人员成长为 Agent 流程设计师。这比等大学培养人才，快至少 4 年。

最后：写给正在选专业的人，也写给正在招人的你

如果你是一位正在帮孩子选专业的高考生家长：选 AI 方向没错，但别只看专业名称里有"人工智能"四个字。看看产业链上真正缺的是什么岗位——部署、调试、流程设计、维保。这些才是 4 年后企业真正愿意买单的能力。

如果你是一位正在发愁"招不到 AI 人才"的企业负责人：别等了。现在的 AI Agent 部署门槛已经不是 2023 年的水平了。一台算力服务器、一套 Dify 工作流、一个愿意学习的现有员工——起步的成本，比你想象的更低。

选专业不是在选一所大学的标签，是在选 4 年后谁愿意为你的能力买单。

而那个买单的人，可能不是 HR。是一个正在工厂角落里盯着 AI Agent 仪表盘、盘算明年能不能再省掉半个编制的老板。
